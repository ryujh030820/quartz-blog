## 1. 연립일차방정식과 가우스-조던 소거법 (Gauss-Jordan Elimination)
선형대수학의 근본적인 과제는 $Ax = b$ 꼴로 표현된 연립일차방정식에서 벡터 $x$를 찾는 것이다. 이를 수행하는 표준적인 방법이 가우스-조던 소거법이다.
### 1.1 기본 원리 및 확장 행렬
연립방정식에서 변수를 제외한 상수 값들만 추출하여 **확장 행렬(Augmented Matrix)** 을 구성한다. 이 행렬에 세 가지 기본 행 연산을 적용하여 왼쪽의 계수 행렬을 **단위 행렬(Identity Matrix)** 로 변환하면, 오른쪽의 상수항 부분이 방정식의 해가 된다.
### 1.2 기본 행 연산 (Elementary Row Operations)
가우스-조던 소거법의 핵심 규칙은 다음의 세 가지로 요약된다:
1. **상수배:** 한 행에 0이 아닌 상수를 곱한다.
2. **행 가감:** 상수배를 한 행을 다른 행에 더하거나 뺀다.
3. **행 교환:** 두 행의 위치를 서로 바꾼다.
## 2. 역행렬(Inverse Matrix)과 행렬의 가역성
역행렬은 $Ax = I$를 만족하는 행렬로, 연립방정식의 해를 직접적으로 구하게 해주는 도구이다.
### 2.1 가우스-조던 소거법을 이용한 유도
역행렬을 구하기 위해 $[A | I]$ 형태의 증가 행렬을 만든 후, 가우스-조던 소거법을 통해 $A$를 $I$로 변환한다. 이 과정이 완료되면 오른쪽의 $I$는 $A^{-1}$로 변하게 된다.
### 2.2 가역 행렬(Invertible Matrix)의 동치 조건
행렬 A가 역행렬을 갖기 위한(Invertible/Non-singular) 조건은 다음과 같다:
- **행렬식(Determinant):** $\text{det}(A) \neq 0$
- **랭크(Rank):** 풀 랭크(Full Rank) 상태여야 함.
- **널 스페이스(Null Space):** 0 벡터만 존재해야 함.
### 2.3 역행렬의 주요 성질

| 성질 구분      | 내용                                             |
| ---------- | ---------------------------------------------- |
| **곱의 역행렬** | $(AB)^{-1} = B^{-1}A^{-1}$ (순서가 바뀜)            |
| **스칼라배**   | $(kA)^{-1} = \frac{1}{k}A^{-1}$                |
| **전치 행렬**  | $(A^T)^{-1} = (A^{-1})^T$                      |
| **행렬식 관계** | $\text{det}(A^{-1}) = \frac{1}{\text{det}(A)}$ |
## 3. 행렬식(Determinant)의 특성과 활용
행렬식은 정사각 행렬에서 추출되는 스칼라 값으로, 해당 행렬의 가역성 등 중요한 정보를 포함하고 있다.
### 3.1 계산 방식: 라플라스 전개 (Laplace Expansion)
$3 \times 3$ 이상의 행렬식은 특정 행이나 열을 기준으로 소행렬식(Minor)들의 합으로 계산하는 '코팩터 전개(Cofactor Expansion)' 방식을 사용한다. 이는 큰 행렬을 작은 행렬들의 행렬식 계산으로 분할하는 기법이다.
### 3.2 주요 성질
- **삼각형렬:** 대각 행렬(Diagonal)이나 삼각 행렬(Triangular)의 행렬식은 대각 성분들의 곱과 같다.
- **선형 종속:** 행렬의 열 벡터 중 하나라도 다른 열들의 조합으로 표현 가능하면(Linearly Dependent), 행렬식은 0이 된다.
- **전치와 곱:** $\text{det}(A^T) = \text{det}(A)이며, \text{det}(AB) = \text{det}(A)\text{det}$(B)이다.
- **고윳값과의 관계:** 행렬식은 모든 고윳값(Eigenvalue)의 곱과 같다.
## 4. 트레이스(Trace)의 정의와 분석적 위상
트레이스는 정사각 행렬의 주대각 성분을 모두 더한 값을 의미하며, 수학적 최적화 및 행렬 미분에서 핵심적인 역할을 수행한다.
### 4.1 최적화에서의 중요성
손실 함수(Loss Function) 등을 최소화할 때, 행렬 형태의 데이터를 크기 비교가 가능한 스칼라 값으로 변환해야 한다. 트레이스는 행렬을 단일 숫자로 요약해주어 크기 비교와 미분을 수월하게 만든다.
### 4.2 주요 성질
1. **선형성:** $\text{tr}(A + B) = \text{tr}(A) + \text{tr}(B), \text{tr}(cA) = c \cdot \text{tr}(A)$
2. **전치 불변:** $\text{tr}(A^T) = \text{tr}(A)$
3. **순환 성질 (Cyclic Property):** $\text{tr}(ABC) = \text{tr}(BCA) = \text{tr}(CAB)$ (단, 순환적인 위치 이동만 허용되며 임의의 순서 교환은 불가함)
4. **고윳값과의 관계:** 트레이스는 행렬의 모든 고윳값의 합과 같다.
## 5. 최소자승법(Least Squares)과 정사영 행렬 (Projection Matrix)
실제 데이터 분석 환경에서는 $Ax = b$의 해가 존재하지 않는 경우가 빈번하다. 이때 오차를 최소화하는 최적의 해를 찾는 방법이 최소자승법이다.
### 5.1 문제 상황과 기하학적 접근
벡터 $b$가 $A$의 열 공간(Column Space) 내부에 존재하지 않을 때, $Ax$가 $b$와 가장 가까워지는 지점은 에러 벡터 $e = b - Ax$가 $A$의 열 공간과 **수직(Orthogonal)** 을 이룰 때이다.
### 5.2 정규 방정식(Normal Equation)과 해 도출
에러 벡터와 $A$의 내적이 0이 되어야 한다는 조건을 전개하면 다음과 같은 정규 방정식을 얻는다:
$$A^TA\hat{x} = A^Tb$$
여기서 $A$가 풀 컬럼 랭크(Full Column Rank)를 가지면 $A^TA$의 역행렬이 존재하며, 최적해 $\hat{x}$는 다음과 같다: $\hat{x} = (A^TA)^{-1}A^Tb$
### 5.3 정사영 행렬 (Projection Matrix)
벡터 $b$를 $A$의 열 공간 위로 투영시키는 행렬 $P$는 다음과 같이 정의된다:
$$P = A(A^TA)^{-1}A^T$$
이 행렬을 $b$에 곱하면($Pb = A\hat{x}$), $b$와 가장 가까운 $A$의 열 공간 내 벡터를 얻을 수 있다. 이는 노이즈가 포함된 측정값에서 원래의 신호를 추정하는 등 다양한 실무적 상황에 응용된다.
