## 1. 최대 가능도 학습의 한계와 GAN의 등장 배경
기존의 생성 모델(Autoregressive, VAE, Normalizing Flows 등)은 주로 모델이 데이터 포인트에 할당하는 확률인 '가능도(Likelihood)'를 최대화하는 방식으로 학습되었다.
### 1.1 최대 가능도(Maximum Likelihood)의 특성
- **원칙적 접근:** 데이터 분포와 모델 분포 사이의 KL 발산(KL Divergence)을 최소화하는 것과 동일하며, 데이터 효율성 측면에서 이론적으로 최적일 수 있다.
- **압축 문제와의 연관성:** 높은 가능도를 달성하는 것은 데이터를 효과적으로 압축하는 것과 같으며, 이는 데이터의 패턴을 이해하고 있음을 시사한다.
### 1.2 가능도와 샘플 품질의 괴리
강의는 높은 가능도가 반드시 좋은 샘플 품질을 보장하지 않으며, 반대로 샘플 품질이 뛰어나다고 해서 가능도가 높은 것도 아니라는 점을 강조한다.
- **나쁜 샘플, 높은 가능도:** 데이터 분포 1%와 순수 노이즈 99%를 혼합한 모델은 99%의 쓰레기 샘플을 생성하지만, 가능도 수치는 최적값에 매우 가깝게 나타날 수 있다.
- **좋은 샘플, 낮은 가능도:** 훈련 세트를 그대로 암기한 오버피팅 모델은 완벽한 품질의 샘플을 출력하지만, 테스트 데이터에 대한 가능도는 0에 가깝다.

## 2. 두 표본 검정(Two-Sample Test)을 통한 분포 비교
GAN은 두 분포가 동일한지 판단하는 통계적 방법인 '두 표본 검정'을 학습 과정에 도입한다.
- **가설 설정:**
    - 귀무가설($H_0$): 데이터 분포($P_{data}$)와 모델 분포($P_{\theta}$)가 동일하다.
    - 대립가설($H_1$): 두 분포가 서로 다르다.
- **검정 통계량의 학습:** 기존의 평균이나 분산 비교와 같은 수작업 통계량은 고차원 데이터에서 한계가 있다. GAN은 신경망(판별자)을 사용하여 두 표본을 가장 잘 구별할 수 있는 최적의 통계량을 **직접 학습**한다.
- **핵심 직관:** "만약 어떤 고성능 분류기(판별자)도 진짜 데이터와 가짜 데이터를 구별해내지 못한다면, 두 분포는 매우 유사한 것이다."
## 3. GAN의 구조와 미니맥스(Minimax) 게임
GAN은 두 개의 신경망이 서로 경쟁하는 구조로 설계된다.
### 3.1 주요 구성 요소

| 구성 요소                        | 역할       | 상세 설명                                                                  |
| ---------------------------- | -------- | ---------------------------------------------------------------------- |
| **생성자 (Generator, $G$)**     | 가짜 샘플 생성 | 잠재 변수 $z$(노이즈)를 입력받아 데이터 공간의 샘플로 매핑. 역함수나 결정론적 제약이 없는 자유로운 아키텍처 사용 가능. |
| **판별자 (Discriminator, $D$)** | 진위 판별    | 입력된 샘플이 실제 데이터일 확률을 출력하는 이진 분류기.                                       |

### 3.2 미니맥스 최적화 목적 함수
GAN의 학습은 다음의 목적 함수 V(G, D)를 이용한 게임으로 정의된다:
$$\min_{G} \max_{D} V(D, G) = \mathbb{E}_{x \sim P_{data}}[\log D(x)] + \mathbb{E}_{z \sim P_z}[\log(1 - D(G(z)))]$$
- **판별자($D$)의 목표:** 실제 데이터($x$)에는 1을, 생성된 데이터($G(z)$)에는 0을 할당하여 $V$를 최대화한다.
- **생성자($G$)의 목표:** 판별자가 $G(z)$를 실제 데이터로 착각하게 만들어 $V$를 최소화한다.
### 3.3 수학적 결론: 젠슨-섀넌 발산 (JSD)
이론적으로 판별자가 최적일 때, GAN의 목적 함수를 최소화하는 것은 데이터 분포와 모델 분포 사이의 **젠슨-섀넌 발산(Jensen-Shannon Divergence, JSD)** 을 최소화하는 것과 같다. JSD는 KL 발산과 달리 대칭적이며 항상 유한한 값을 갖는 특징이 있다.

## 4. GAN의 장점과 한계
### 4.1 주요 장점
- **유연한 아키텍처:** 가능도를 직접 계산할 필요가 없으므로 생성자 설계 시 가역성(Invertibility)이나 정규화(Normalization) 제약이 없다.
- **빠른 샘플링:** 오토레그레시브 모델과 달리, 신경망의 단일 통과(Single Pass)만으로 샘플 생성이 가능하다.
- **지각적 우수성:** 가능도 보다는 샘플의 특징을 잡아내는 데 특화되어 있어 시각적으로 선명한 이미지를 생성한다.
### 4.2 실무적 한계 및 문제점
- **학습의 불안정성:** 두 명의 플레이어가 경쟁하는 구조이므로 수렴이 보장되지 않고 손실 함수가 진동하는 경우가 많다.
- **모드 붕괴 (Mode Collapse):** 생성자가 다양한 데이터를 만들지 못하고 판별자를 속이기 쉬운 특정 유형의 샘플(예: 특정 숫자 하나)만 반복해서 생성하는 현상.
- **정지 기준 부재:** 가능도 기반 모델처럼 '최대치'에 도달했는지 판단할 수 있는 지표가 부족하여, 사람이 직접 샘플을 보고 판단해야 하는 경우가 많다.
## 5. 결론 및 향후 전망
강의는 GAN이 생성 모델 분야에 혁신적인 아이디어를 제공했음을 인정하면서도, 현재의 기술적 위치를 객관적으로 진단한다.
"GAN은 강력한 아이디어이며 매우 성공적이었지만, 학습이 극도로 어렵다는 단점 때문에 많은 이들이 더 안정적인 확산 모델(Diffusion Models)로 이동했다."
하지만 GAN의 **적대적 손실(Adversarial Loss)** 개념은 여전히 유효하다. 최근에는 확산 모델이나 VAE 등 다른 모델의 출력물을 더 정교하게 다듬기 위한 보조적인 신호로 GAN의 판별자를 결합하는 방식이 활발히 연구되고 있다. 이는 GAN이 단독 모델로서의 인기는 줄었을지라도, 생성 모델의 성능 향상을 위한 핵심 메커니즘으로서 여전히 중요한 가치를 지님을 시사한다.
