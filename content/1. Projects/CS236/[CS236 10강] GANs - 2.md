## 1. 핵심 요약 (Executive Summary)
생성 적대 신경망(GAN)은 데이터의 확률 밀도 함수를 직접 평가하지 않고도 복잡한 분포를 학습할 수 있는 **우도 무관(Likelihood-free)** 학습 프레임워크를 제공한다. 본 문서의 주요 통찰은 다음과 같다:
- **학습 원리:** 생성자(Generator)와 판별자(Discriminator) 사이의 **미니맥스(Minimax) 게임**을 통해 데이터 분포를 모사한다. 최적의 판별자는 두 분포 사이의 밀도 비율(Density ratio)을 계산하며, 이는 본질적으로 젠슨-섀넌 발산(Jensen-Shannon Divergence, JSD)을 최소화하는 것과 같다.
- **이론적 확장 (f-GAN):** 펜첼 켤레(Fenchel conjugate)를 이용한 변분 다이버전스 최소화 기법을 통해, JSD뿐만 아니라 KL 발산, 역 KL 발산 등 **f-발산(f-divergence)** 클래스 전체로 GAN의 목적 함수를 일반화할 수 있다.
- **학습 안정성 (WGAN):** 두 분포의 지지집합(Support)이 겹치지 않을 때 발생하는 기울기 소실 문제를 해결하기 위해 **와세스타인 거리(Wasserstein Distance)** 를 도입한다. 이는 립시츠(Lipschitz) 연속성 제약을 통해 더욱 안정적인 학습 신호를 제공한다.
- **잠재 표현 추론 (BiGAN):** 생성 모델의 잠재 변수 z를 역으로 추론하기 위해 **양방향 GAN(BiGAN)** 구조를 사용하며, 이는 인코더를 포함하여 (x, z) 쌍의 결합 분포를 학습한다.
- **도메인 변환:** **CycleGAN**은 쌍을 이루지 않는(Unpaired) 데이터셋 간의 변환을 가능하게 하며, 순환 일관성(Cycle consistency) 손실을 통해 두 도메인 간의 구조적 관계를 유지한다.
## 2. GAN의 기초와 우도 무관 학습
### 2.1 우도 무관 학습의 이점
기존의 최대 우도(Maximum Likelihood) 학습은 모델의 확률 밀도 함수 $P_\theta(x)$를 직접 평가해야 하므로, 계산 가능한 특수한 아키텍처(자기 회귀 모델, 가역 네트워크 등)를 강제하는 한계가 있다. 반면 GAN은 다음을 가능하게 한다:
- 확률 분포를 체인 룰(Chain rule)에 따라 분해할 필요가 없음.
- 단순한 사전 분포(Prior, 예: Gaussian)로부터 신경망을 통과시켜 샘플을 생성하는 **암묵적 모델(Implicit models)** 사용 가능.
- 샘플링만 가능하면 학습이 가능하므로 모델 설계의 유연성이 극대화됨.
### 2.2 미니맥스 목적 함수
GAN의 기본 학습 목표는 다음과 같은 미니맥스 게임으로 정의된다:
$$\min_G \max_D V(G, D) = \mathbb{E}_{x \sim p_{data}}[\log D(x)] + \mathbb{E}_{z \sim p(z)}[\log(1 - D(G(z)))]$$
여기서 판별자 D는 실제 데이터와 가짜 샘플을 구분하도록 훈련되고, 생성자 G는 판별자를 속이도록 훈련된다.
## 3. f-GAN: 발산(Divergence)의 일반화
### 3.1 f-발산의 정의와 특성
두 밀도 함수 p와 q 사이의 f-발산은 다음과 같이 정의된다:
$$D_f(p, q) = \mathbb{E}_{x \sim q} \left[ f\left(\frac{p(x)}{q(x)}\right) \right]$$
이때 $f$는 $f(1)=0$을 만족하는 볼록(Convex) 함수이며 하반연속(Lower semi-continuous)이어야 한다. 선택하는 f에 따라 다양한 발산 지표가 도출된다.

### 3.2 펜첼 켤레(Fenchel Conjugate)를 이용한 변분 하한
우리는 데이터의 실제 밀도 $p_{data}$를 알 수 없으므로 직접적인 f-발산 계산이 불가능하다. 이를 해결하기 위해 펜첼 켤레 함수 $f^*$를 도입하여 하한(Lower bound)을 구한다:
$$D_f(p, q) \geq \sup_{T \in \mathcal{T}} (\mathbb{E}_{x \sim p}[T(x)] - \mathbb{E}_{x \sim q}[f^*(T(x))])$$
이 공식은 우도(Likelihood) 평가 없이 샘플만으로 발산 값을 근사할 수 있게 하며, 이는 신경망 T를 판별자로 사용하는 f-GAN의 토대가 된다.

## 4. Wasserstein GAN (WGAN)
### 4.1 f-발산의 한계: 지지집합의 불연속성
데이터 분포 $p$와 모델 분포 $q$의 지지집합이 겹치지 않는 경우(예: 고차원 공간 내의 저차원 매니폴드), KL이나 JSD는 상숫값을 가지거나 무한대로 발산하여 학습을 위한 기울기(Gradient)를 제공하지 못한다.
### 4.2 Earth-Mover Distance (Wasserstein-1 거리)
와세스타인 거리는 한 분포의 질량을 다른 분포로 이동시키는 데 드는 최소 비용으로 정의된다:
$$W(p, q) = \inf_{\gamma \in \Pi(p, q)} \mathbb{E}_{(x, y) \sim \gamma}[\|x - y\|]$$
이 지표는 두 분포가 멀리 떨어져 있더라도 거리 d에 비례하는 부드러운 그래디언트를 제공하여 학습 안정성을 획기적으로 높인다.

### 4.3 립시츠 제약 (Lipschitz Constraint)
칸토로비치-루빈슈타인 쌍대성(Kantorovich-Rubinstein duality)에 의해 WGAN의 목적 함수는 다음과 같이 변환된다:
$$\min_G \max_{\|f\|_L \leq 1} \mathbb{E}_{x \sim p_{data}}[f(x)] - \mathbb{E}_{x \sim p_G}[f(x)]$$
함수 f가 **립시츠 상수 1**을 유지하도록 하기 위해 실무에서는 **가중치 클리핑(Weight clipping)** 또는 **그래디언트 페널티(Gradient penalty)** 기법을 사용한다.
## 5. GAN의 확장 모델 및 응용
### 5.1 잠재 표현 추론 (BiGAN)
표준 GAN은 $z \to x$ 방향의 매핑만 학습하므로 데이터로부터 특징(Feature)을 추출하는 인코더가 없다. **양방향 GAN(BiGAN)** 은 이를 보완한다:
- **구조:** 생성자 $G(z)$와 인코더 $E(x)$를 동시에 학습.
- **판별자:** 데이터 샘플 $x$만 보는 대신, 쌍 $(x, E(x))$와 $(G(z), z)$를 입력받아 어느 쪽이 실제 데이터-추론 잠재 변수 쌍인지 판별.
- **결과:** 학습 완료 후 인코더 E는 특징 추출기나 전이 학습의 기반으로 활용 가능하다.
### 5.2 도메인 간 변환 (CycleGAN)
서로 다른 두 도메인 $X$와 $Y$ 사이의 관계를 쌍이 없는 데이터로부터 학습한다.
- **순환 일관성(Cycle Consistency):** 도메인 $X$의 이미지를 $Y$로 변환($G$)했다가 다시 $X$로 역변환($F$)했을 때 원래 이미지와 유사해야 함($F(G(x)) \approx x$).
- **응용:** 사진을 명화(모네, 반 고흐 등) 스타일로 변경하거나, 말(Horse)을 얼룩말(Zebra)로 변환하는 등의 작업에 사용된다.
- **변형 모델:**
    - **AlignFlow:** 가역적 Flow 모델을 사용하여 엄격한 순환 일관성을 보장하고 최대 우도 학습을 결합.
    - **StarGAN:** 단일 생성기로 여러 도메인 간의 변환을 동시에 수행.
## 6. 결론
GAN은 샘플링 기반의 학습 방식을 통해 생성 모델의 새로운 패러다임을 제시했다. 초기의 JSD 최소화 방식에서 나아가 f-발산 일반화와 와세스타인 거리 도입을 통해 학습의 수렴성과 안정성을 개선해 왔다. 또한 BiGAN과 CycleGAN 같은 모델들은 단순한 샘플 생성을 넘어 잠재 표현의 이해와 복잡한 데이터 도메인 간의 매핑이라는 실질적인 가치를 제공한다.
