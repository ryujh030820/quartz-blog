## 1. 핵심 요약 (Executive Summary)

- **생성형 모델의 본질:** 미지의 데이터 생성 프로세스($P_{data}$)를 근사하는 확률 분포($P_\theta$)를 학습하는 것이다. 성공적인 근사를 통해 새로운 데이터 생성(Sampling), 이상 탐지(Density Estimation), 비지도 특징 학습(Feature Discovery)이 가능해진다.
- **차원의 저주(Curse of Dimensionality):** 이미지나 텍스트와 같은 고차원 데이터의 경우, 가능한 상태의 수가 기하급수적으로 증가하여 일반적인 방식으로는 확률 분포를 표현하거나 학습하는 것이 불가능하다.
- **구조적 해결책:** 복잡한 결합 확률 분포를 단순화하기 위해 독립성(Independence) 가정, 조건부 독립성(Conditional Independence), 확률 연쇄 법칙(Chain Rule)을 활용한다. 베이지안 네트워크(Bayesian Networks)는 이러한 구조적 가정을 그래프 형태로 표현한 도구이다.
- **신경망 모델로의 진화:** 전통적인 표(Table) 기반 표현의 한계를 극복하기 위해 신경망을 사용하여 조건부 분포의 함수적 형태를 파라미터화한다. 이는 로지스틱 회귀에서 딥 뉴럴 네트워크, 더 나아가 오토레그레시브(Auto-regressive) 모델과 변이형 오토인코더(VAE)의 기초가 된다.

## 2. 생성형 모델의 정의 및 학습 목표

생성형 모델 학습의 기본 전제는 가용한 데이터 포인트들이 어떤 미지의 확률 분포 P\_{data}에서 샘플링되었다는 것이다.

### 2.1 주요 학습 목적

- **샘플링(Generation):** 학습된 모델 $P_\theta$에서 새로운 샘플 $x_{new}$를 생성한다. 모델이 우수할수록 생성된 데이터는 실제 데이터와 유사한 특성을 갖는다.
- **밀도 추정(Density Estimation):** 입력값 $x$에 대해 모델이 얼마나 높은 확률을 부여하는지 확인한다. 이를 통해 이상 탐지(Anomaly Detection)나 데이터의 타당성 추론이 가능하다.
- **비지도 표현 학습(Unsupervised Representation Learning):** 라벨이 없는 대규모 데이터로부터 데이터의 공통 구조나 변동 축(Features)을 스스로 학습한다.

### 2.2 모델 학습 프로세스

1. **데이터 수집:** 이미지, 텍스트, DNA 시퀀스 등 실제 데이터 샘플 확보.
2. **모델 패밀리 정의:** 파라미터 $\theta$로 인덱싱된 확률 분포의 집합 $P_\theta$ 설정.
3. **손실 함수 및 최적화:** $P_{data}$와 $P_\theta$ 사이의 유사도(Similarity Metric)를 정의하고, 두 분포 사이의 거리를 최소화하도록 $\theta$를 최적화한다.

## 3. 차원의 저주와 표현의 문제

데이터의 차원이 높아질수록 이를 표현하기 위한 파라미터의 수는 기하급수적으로 증가한다.

### 3.1 파라미터 폭발 예시

- **단일 픽셀(RGB):** 각 채널이 0-255 값을 가질 때, 한 픽셀의 색상을 완전히 표현하려면 $256^3 - 1$개의 파라미터가 필요하다.
- **흑백 이미지:** $n$개의 이진 픽셀로 구성된 이미지의 가능한 상태 수는 $2^n$개이며, 이를 표현하기 위한 파라미터는 $2^n - 1$개가 필요하다. $n$이 조금만 커져도 우주의 원자 수보다 많은 파라미터가 필요하게 되어 컴퓨터에 저장하거나 학습하는 것이 불가능해진다.

### 3.2 독립성 가정의 한계

모든 변수가 독립적이라고 가정하면 파라미터 수를 $n$개로 줄일 수 있으나, 이는 픽셀 간의 관계를 완전히 무시하므로 구조가 있는 데이터를 모델링하기에는 너무 강력하고 부적절한 가정이다.

## 4. 구조적 모델링: 베이지안 네트워크와 연쇄 법칙

복잡한 분포를 다루기 위해 확률론적 규칙을 사용하여 결합 분포를 더 단순한 요소들로 분해한다.

### 4.1 핵심 확률 규칙

- **연쇄 법칙(Chain Rule):** 결합 분포를 조건부 분포들의 곱으로 분해한다.
  - $p(x_1, \dots, x_n) = p(x_1)p(x_2|x_1)p(x_3|x_1, x_2) \dots p(x_n|x_1, \dots, x_{n-1})$
  - 여전히 마지막 조건부 분포들은 지수적인 파라미터 수를 요구한다.
- **베이즈 정리(Bayes' Rule):** 사전 확률과 우도를 통해 사후 확률을 계산한다.

### 4.2 베이지안 네트워크(Bayesian Networks)

방향성 비순환 그래프(DAG)를 사용하여 변수 간의 조건부 독립성을 표현하는 데이터 구조이다.

- **특징:** 각 노드는 확률 변수를 나타내며, 각 노드에 대해 부모 노드에 조건화된 조건부 확률 분포(CPD)를 지정한다.
- **경제성:** 전체 결합 분포를 직접 다루는 대신, 국소적인 상호작용(부모-자식 관계)만 모델링하여 파라미터 수를 획기적으로 줄인다. 복잡도는 부모 노드의 수에 지수적으로 비례한다.

## 5. 생성형 모델 vs. 판별형 모델

데이터 X와 라벨 Y 사이의 관계를 모델링하는 방식에 따라 두 가지 접근법으로 나뉜다.

|                 |                                                                   |                                                                                 |
| --------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 구분            | 생성형 모델 (Generative)                                          | 판별형 모델 (Discriminative)                                                    |
| **모델링 대상** | 결합 분포 $P(X, Y)$ 또는 $P(X)$                                   | 조건부 분포 $P(Y \mid X)$                                                       |
| **특징**        | 입력 데이터의 분포($P(X)$)까지 학습함.                            | $X$가 주어졌을 때 $Y$를 예측하는 데만 집중함.                                   |
| **장점**        | 결측치 추론 가능, 데이터 생성 가능, 입력 데이터에 대한 추론 가능. | 분류 작업에서 $P(X)$를 모델링할 필요가 없어 효율적이고 성능이 좋은 경우가 많음. |
| **예시**        | 나이브 베이즈(Naive Bayes)                                        | 로지스틱 회귀(Logistic Regression)                                              |

### 5.1 나이브 베이즈와 로지스틱 회귀의 비교

- **나이브 베이즈:** 라벨 $Y$가 주어졌을 때 특징 $X_i$들이 독립이라는 강한 가정을 한다. 데이터가 적을 때 유용하지만, 상관관계가 있는 특징(예: 스팸 메일의 'bank'와 'account')을 중복 계산하는 경향이 있다.
- **로지스틱 회귀:** 특징 간의 독립성을 가정하지 않고 $P(Y|X)$의 함수적 형태(선형 결합 + 시그모이드)를 가정한다. 데이터가 충분할 때 나이브 베이즈보다 강력한 성능을 보인다.

## 6. 신경망 기반의 생성 모델 (Neural Models)

전통적인 베이지안 네트워크의 표 기반 CPD를 신경망으로 대체함으로써 유연성과 표현력을 확보한다.

### 6.1 선형에서 비선형으로의 확장

- **로지스틱 회귀:** 입력 $X$의 선형 결합을 시그모이드 함수에 통과시킨다. 이는 결정 경계가 선형이라는 제약이 있다.
- **신경망 모델:** 입력을 비선형 변환($h = f(Ax+b)$)하여 특징을 추출한 뒤 회귀를 수행한다. 레이어를 깊게 쌓음으로써 매우 복잡한 함수 관계를 근사할 수 있다.

### 6.2 딥 생성 모델의 구성

- **오토레그레시브 모델:** 연쇄 법칙을 유지하되, 각 조건부 분포를 신경망으로 모델링한다. (예: 대규모 언어 모델)
- **변이형 오토인코더(VAE):** 잠재 변수 $Z$로부터 데이터 $X$를 생성하는 간단한 베이지안 네트워크($Z \to X$) 구조를 갖는다. 이때 $X$의 파라미터(평균 $\mu$, 분산 $\sigma$)를 신경망의 출력값으로 결정한다.

## 7. 연속 확률 변수의 처리

이미지 픽셀 강도와 같은 연속적인 데이터는 확률 밀도 함수(PDF)를 사용하며, 가우시안(Gaussian)이나 균등(Uniform) 분포와 같은 파라미터화된 함수 형태를 가정한다.

- **혼합 가우시안 모델(Mixture of Gaussians):** 이산형 잠재 변수 Z를 사용하여 여러 가우시안 분포를 결합함으로써 더 복잡한 형태의 밀도를 표현한다.
- **연속성 모델링의 핵심:** 연쇄 법칙과 베이즈 정리는 연속 변수에도 동일하게 적용되며, 이를 신경망과 결합하여 현대적인 딥 생성 모델의 기반을 형성한다.
