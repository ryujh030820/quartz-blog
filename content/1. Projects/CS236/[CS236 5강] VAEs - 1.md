## 1. 잠재 변수 모델(LVM)의 개요 및 동기
### 1.1 자기회귀 모델과의 비교
자기회귀 모델은 연쇄 법칙(Chain rule)을 사용하여 결합 확률 분포를 조건부 분포의 곱으로 분해한다.

| 구분     | 자기회귀 모델 (Autoregressive)  | 잠재 변수 모델 (Latent Variable) |
| ------ | ------------------------- | -------------------------- |
| **장점** | 우도 평가 용이, 최대 우도 학습 가능     | 유연한 모델링, 비지도 특징 학습 가능      |
| **단점** | 생성 속도 저하(순차적), 특징 추출의 어려움 | 우도 평가 및 학습의 복잡성(계산 비용)     |
### 1.2 잠재 변수($z$)의 역할
이미지 데이터에서 성별, 눈의 색깔, 머리색, 포즈 등은 데이터의 변동성을 만드는 주요 요인이지만 명시적인 주석(Annotation)이 없는 경우가 많다. LVM은 이러한 요인들을 **잠재 변수 $z$** 로 설정한다.
- **효율성:** 적절한 $z$를 선택하면 $p(x|z)$를 단순하게 모델링하더라도 전체 $p(x)$를 효과적으로 표현할 수 있다.
- **표현 학습:** 학습된 모델을 통해 역으로 $p(z|x)$를 추론함으로써 데이터의 고수준 특징을 추출할 수 있다.
## 2. 주요 잠재 변수 모델 분석
### 2.1 가우시안 혼합 모델 (Mixture of Gaussians, GMM)
가장 단순한 형태의 '얕은(Shallow)' 잠재 변수 모델이다.
- **구조:** $z$는 범주형 변수(Categorical)로, 어떤 혼합 성분(Component)에서 데이터가 생성되었는지를 결정한다.
- **생성 과정:** 먼저 $z$를 샘플링하여 성분을 선택한 후, 해당 가우시안 분포에서 $x$를 샘플링한다.
- **비지도 학습:** 레이블이 없는 데이터에서 클러스터링을 수행하는 용도로 사용된다(예: MNIST 숫자의 비지도 분류).
### 2.2 변분 오토인코더 (Variational Autoencoder, VAE)
가우시안 혼합 모델을 무한한 수의 성분으로 확장하고 심층 신경망을 결합한 형태이다.
- **구조:**
    - $z \sim \mathcal{N}(0, I)$ (단순한 가우시안 사전 분포)
    - $p(x|z) = \mathcal{N}(\mu_\theta(z), \Sigma_\theta(z))$
- **심층 모델링:** 신경망 $\mu_\theta(z)$와 $\Sigma_\theta(z)$가 z로부터 데이터 x의 평균과 분산을 예측한다.
- **복잡성:** $p(x|z)$는 단순한 가우시안이지만, 신경망을 통한 비선형 매핑을 거쳐 이를 무한히 혼합함으로써 매우 복잡하고 유연한 주변 분포 $p(x)$를 생성한다.
## 3. 학습 및 추론의 난제: 주변 우도(Marginal Likelihood)
잠재 변수가 포함된 모델의 최대 우도 학습(Maximum Likelihood Learning)을 위해서는 로그 주변 우도 $\log p(x;\theta)$를 최적화해야 한다.
$$\log p(x;\theta) = \log \int p(x, z; \theta) dz$$
- **계산 불가능성:** $z$가 고차원이거나 연속적일 때, 이 적분(또는 합산)을 수행하는 것은 매우 비용이 많이 들거나 불가능하다. 예를 들어 30개의 이진 잠재 변수만 있어도 $2^{30}$개의 항을 계산해야 한다.
- **경사도 계산의 어려움:** $\nabla_\theta \log p(x;\theta)$ 역시 직접 계산하기 어렵다.
## 4. 변분 추론과 증거 하한(ELBO)
### 4.1 몬테카를로 접근법의 한계
- **나이브 몬테카를로:** $z$를 균등하게 샘플링하여 기댓값을 추정하지만, 대부분의 $z$는 우도가 매우 낮아 분산이 크고 비효율적이다.
- **중요도 샘플링(Importance Sampling):** 제안 분포 $q(z)$를 사용하여 의미 있는 $z$를 더 자주 샘플링한다. 하지만 로그 우도를 추정할 때 로그 함수와 기댓값의 순서를 바꿀 수 없어 편향(Bias)이 발생한다.
### 4.2 [[[개념 정리] Jensen's inequality - 옌센 부등식|젠슨 부등식]]과 ELBO 유도
로그 함수가 오목 함수(Concave function)라는 점을 이용하여 젠슨 부등식을 적용하면 **증거 하한(ELBO)** 을 얻을 수 있다.
$$\log \left( \mathbb{E}_{z \sim q(z)} \left[ \frac{p_\theta(x, z)}{q(z)} \right] \right) \ge \mathbb{E}_{z \sim q(z)} \left[ \log \frac{p(x, z; \theta)}{q(z)} \right] = \mathcal{L}(x; \theta, \phi)$$
- **ELBO의 구성:** 로그 결합 확률의 기댓값과 $q(z)$의 엔트로피 $H(q)$의 합으로 표현될 수 있다.
	- 증명
		![[Pasted image 20260321215914.png|400]]
- **타이트함(Tightness):** $q(z)$가 진정한 사후 분포 $p(z|x;\theta)$와 일치할 때 하한은 실제 로그 우도와 같아진다.
### 4.3 변분 매개변수 $\phi$의 도입
진정한 사후 분포 $p(z|x;\theta)$는 계산이 불가능하므로, 다루기 쉬운 분포 가족 $q(z;\phi)$(예: 가우시안)를 설정하고 최적의 $\phi$를 찾는다.
- **최적화 목표:** KL 발산 $D_{KL}(q(z;\phi) || p(z|x;\theta))$을 최소화하는 것은 ELBO를 최대화하는 것과 같다.

- **결과:** 모델 매개변수 $\theta$와 변분 매개변수 $\phi$를 동시에 최적화하여 데이터의 우도를 간접적으로 최대화한다.
## 5. 결론 및 향후 과제
잠재 변수 모델은 단순한 빌딩 블록을 사용하여 복잡한 분포를 정의할 수 있는 강력한 프레임워크를 제공한다. 특히 VAE는 비지도 학습 환경에서 데이터의 잠재적 구조를 파악하는 데 유용하다.
- **한계:** 우도 평가 및 학습이 여전히 직접적이지 않으며, 변분 근사에 의존해야 한다.
- **차기 논점:** ELBO 최적화를 위해 모델을 종단간 미분 가능하게(End-to-end differentiable) 만드는 방법과 구체적인 학습 알고리즘이 다뤄질 예정이다.
