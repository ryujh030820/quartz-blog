## 1. 핵심 요약 (Executive Summary)
- **Muon의 등장 배경:** 기존의 표준 최적화 도구인 Adam은 메모리 사용량이 많고, 모델 파라미터의 내부 행렬 구조를 무시한 채 벡터로 취급한다는 한계가 있었다.
- **주요 혁신:** Muon은 모멘텀 행렬을 **직교화(Orthogonalization)** 하여 희소한 학습 방향을 증폭시킨다. 이를 통해 AdamW 대비 약 **2배의 계산 효율성**을 달성하며, 더 적은 메모리로 더 빠른 학습 속도를 구현한다.
- **기술적 구현:** 연산 비용이 높은 특이값 분해(SVD) 대신, **Newton-Schulz 반복법(홀수 다항식 함수)** 을 사용하여 GPU 환경에서 효율적으로 직교 행렬을 근사한다.
- **학습 안정성:** 대규모 모델 확장을 위해 **Weight Decay**와 **학습률 조정**을 도입했으며, 특히 어텐션 로짓(Attention Logits)의 폭주를 막기 위해 **QK Clip** 및 **Muon Clip** 기술을 적용하여 학습의 안정성을 극대화했다.
## 2. 기존 Adam 최적화 도구의 한계 분석
학습 과정에서 최적의 파라미터를 찾는 최적화 도구로 오랫동안 Adam이 사용되어 왔으나, 다음과 같은 구조적 결함이 지적되어 왔다.
- **메모리 오버헤드:** Adam은 모멘텀(Momentum)과 제곱 그래디언트(Square Gradients)라는 두 가지 지수 이동 평균 변수를 유지해야 한다. 이로 인해 최적화 상태 데이터가 모델 파라미터 자체보다 약 2배 더 많은 메모리를 점유한다.
- **구조 정보의 상실:** Adam은 파라미터를 하나의 긴 벡터로 취급(Vector-based)하여 업데이트한다. 이는 신경망의 선형 레이어가 가진 본질적인 행렬 구조를 반영하지 못한다.
- **저차원(Low-rank) 문제:** 벡터 기반 최적화 환경에서 선형 레이어의 모멘텀 행렬은 실제 운용 시 저차원화되는 경향이 있다. 이는 소수의 지배적인 방향만이 업데이트를 주도하고, 세부적인 패턴을 포착할 수 있는 다른 방향들은 무시됨을 의미한다.
## 3. Muon의 핵심 원리: 모멘텀 직교화
Muon은 모멘텀 행렬을 직교화함으로써 Adam의 한계를 극복한다.
### 3.1 직교화의 효과
직교화는 모멘텀 행렬 내의 행과 열이 서로 직교하도록 만드는 과정이다. 이 과정에서 업데이트 빈도가 낮거나 영향력이 작았던 '희소한 방향(Rare directions)'이 증폭된다. 이러한 미세한 방향들이 활성화됨으로써 모델은 데이터 내의 더 정교한 패턴을 포착할 수 있게 된다.
> [!note]
> Muon이 잘 동작하는 진짜 이유는 “모멘텀 직교화” 그 자체가 아니라, 학습 초기에 반랜덤한 잡음을 그래디언트에 더해주는 일종의 정규화(regularization) 역할을 하기 때문이라는 주장도 존재한다. 즉, 초반에 탐색(exploration)을 장려하고, 안장점(saddle point)이나 중복∙퇴화된 파라미터 조합에서 벗어나도록 툭툭 쳐주는 효과가 있어 “좋은 노이즈 정규화 트릭”에 가깝다는 것이다.
### 3.2 이론적 배경: 특이값 분해 (SVD)
행렬 $M$을 직교화하는 가장 확실한 방법은 특이값 분해($M = U \Sigma V^T$)를 사용하는 것이다. 여기서 특이값 행렬 $\Sigma$의 모든 대각 성분을 1로 설정하면, 원래 행렬 $M$에 가장 가까운 직교 행렬 $O$를 얻을 수 있다. 그러나 SVD는 계산 복잡도가 매우 높아 매 업데이트마다 수행하기에는 부적합하다.
## 4. 효율적인 구현: Newton-Schulz 반복법
Muon은 SVD의 대안으로 **Newton-Schulz 반복법**을 사용하여 행렬 직교화를 효율적으로 수행한다.
### 4.1 홀수 다항식(Odd Polynomial) 함수 활용
행렬 $X$에 대해 $X$와 $X X^T X$의 가중치 합을 계산하는 방식이다. 이 함수는 행렬의 특이값들에 직접 작용하여, 명시적인 SVD 계산 없이도 특이값들을 1에 가깝게 수렴시킨다.
- **계수(Coefficients) 설정:**
    - 초기 모델: $a=1.5, b=-0.5, c=0$ (3차 다항식)
    - 최적화된 모델: $a=2, b=-1.5, c=0.5$ (5차 다항식) 등의 계수를 조절하여 수렴 속도를 높인다.

- **수렴 범위:** 특이값을 정확히 1로 만들 필요는 없으며, 실험적으로 0.7에서 1.3 사이의 범위에 들어오도록 설계하는 것만으로 충분한 성능을 발휘한다.

### 4.2 알고리즘 절차
1. 오차 역전파를 통해 그래디언트($G_t$)를 계산한다.
2. 이전 그래디언트의 지수 이동 평균인 모멘텀을 업데이트한다.
3. 2D 모멘텀 행렬의 특이값이 0과 1 사이에 오도록 정규화한다.
4. Newton-Schulz 직교화 과정을 **5회 반복** 수행하여 직교 행렬 $O$를 생성한다.
5. 생성된 $O$를 사용하여 모델 파라미터를 업데이트한다.
이 과정은 순수하게 행렬 곱셈으로만 이루어져 있어 GPU에서 매우 빠르게 연산된다.
## 5. 대규모 모델을 위한 안정성 강화 기법
모델 규모가 커질수록 Muon의 성능 이점이 감소하거나 학습이 불안정해지는 현상이 발생할 수 있다. 이를 해결하기 위해 다음과 같은 추가 기법들이 도입되었다.
### 5.1 가중치 감쇠(Weight Decay) 및 학습률 조정
AdamW와 유사하게 Weight Decay 메커니즘을 추가하고, 2D 행렬의 크기를 고려하여 학습률을 조정함으로써 대규모 모델 학습 시의 안정성을 확보했다.
### 5.2 QK Clip을 통한 어텐션 로짓 제어
학습 중 어텐션 로짓(Attention Logits)이 지나치게 커지면 수치적 불안정성이 발생한다. 이를 방지하기 위해 **QK Clip** 기법이 사용된다.

| 단계        | 설명                                                             |
| --------- | -------------------------------------------------------------- |
| **모니터링**  | 어텐션 로짓의 최댓값이 임계값($\tau$)을 초과하는지 감시한다.                          |
| **비율 계산** | 초과 시 스케일링 비율($\gamma$)을 계산한다.                                  |
| **재조정**   | 쿼리($W_Q$)와 키($W_K$) 파라미터 행렬에 각각 $\sqrt{\gamma}$를 곱하여 스케일을 낮춘다. |
### 5.3 DeepSeek MLA 대응: MuonClip
DeepSeek에서 제안한 **MLA(Multi-head Latent Attention)** 와 같은 복잡한 구조에서는 스케일링이 더 까다롭다.
- **개별 헤드 스케일링:** 각 헤드별로 독립적인 스케일링 인자를 적용한다.
- **공유 키 관리:** 여러 헤드가 공유하는 '공유 로터리 키 행렬($W_{KR}$)'이 중복 스케일링되는 것을 방지하기 위해, 헤드별 로터리 쿼리($W_{QR}$)만 조정하고 공유 키는 유지하는 **Muon Clip** 방식을 채택한다.

## 6. 결론
Muon 최적화 도구는 행렬 직교화라는 수학적 접근을 통해 기존 AdamW의 구조적 한계를 성공적으로 극복했다. Newton-Schulz 반복법을 통한 효율적인 연산 구현과 QK-Clip/MuonClip을 통한 학습 안정성 확보는 Muon이 차세대 AI 모델 학습의 핵심 도구가 될 수 있음을 입증한다. 특히 동일한 자원으로 더 빠른 학습이 가능하다는 점은 대규모 모델 학습 환경에서 강력한 경쟁 우위를 제공한다.
