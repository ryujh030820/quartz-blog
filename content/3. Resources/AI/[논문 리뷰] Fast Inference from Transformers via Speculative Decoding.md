## Introduction
대규모 자기회귀 모델, 특히 Transformer는 최근 몇 년간 텍스트나 이미지 도메인에서 소규모 모델보다 훨씬 뛰어난 성능을 보인다.
불행히도 이런 대규모 모델에서의 단일 디코딩 단계는 소규모 모델보다 훨씬 느리며, 더 나쁜 점은 이러한 단계가 직렬로 수행된다는 것이다.
즉, $K$개의 토큰을 디코딩하려면 모델을 $K$번 직렬로 실행해야 한다.

기존에도 이를 해결하기 위해 다른 솔루션들이 존재했지만 일반적으로 <u>모델 아키텍처를 변경하고, 학습 절차를 변경하고, 모델을 재학습해야 하며, 동일한 출력을 유지하지 못한다</u>.
또한 대규모 모델에서의 추론은 종종 산술 연산이 아닌 메모리 대역폭과 통신에 의해 병목 현상이 발생하므로 추가적인 계산 자원을 활용할 수 있다는 점에 주목한다.

따라서 본 연구는 적응형 계산량을 사용하는 방식에 대한 보완적 접근 방식으로 동시성을 높일 것을 제안한다.
구체적으로, 본 연구는 <u>모델 아키텍처를 변경하거나, 학습 절차를 변경하거나, 모델을 재학습할 필요 없이, 그리고 모델 출력 분포를 변경하지 않고도</u> 추론을 가속화할 수 있다.
![[Pasted image 20260716111814.png]]
위 그림은 비조건부 언어 모델링(unconditional language modeling) 사례에 해당 기법을 보여준다.
각 줄은 알고리즘의 한 반복(iteration)을 나타낸다.
녹색 토큰은 근사 모델이 제안한 토큰 중 타겟 모델이 수락한 토큰이며, 빨간색과 파란색 토큰은 각각 거부된 제안과 그에 대한 수정 사항이다.
이 토큰들은 수락될 확률을 극대화하는 동시에, 해당 시스템의 출력이 타겟 모델 단독으로 생성한 출력과 동일한 분포를 갖도록 보장한다.

요약하자면, 본 연구의 주요 기여는 다음과 같다.
1. **speculative sampling**이라고 부르는 새로운 샘플링 방법을 통해 speculative execution 확률적 설정으로 일반화한 것
2. 모델 아키텍처, 학습 체계, 출력 분포를 전혀 변경하지 않고도 자기회귀 모델의 디코딩 속도를 높일 수 있는 **speculative decoding**이라 부르는 디코딩 메커니즘
## Speculative Decoding
### Overview
$M_p$를 추론 속도를 높이려는 타겟 모델이라 하고, $p(x_t|x_{<t})$ 접두사 $x_{<t}$ 대해 모델로부터 얻는 분포라고 하자.
$M_q$를 동일한 작업에 대한 더 효율적인 근사 모델이라 하고, $q(x_t|x_{<t})$를 접두사 $x_{<t}$ 대해 모델로부터 얻는 분포라고하자.
핵심 아이디어는
1. 더 효율적인 모델 $M_q$를 사용하여 $\gamma \in \mathbb{Z}^+$개의 완성본을 생성하고
2. 타겟 모델 $M_p$를 사용하여 $M_q$로부터 모든 추측과 각 확률을 병렬로 평가하여 동일한 분포를 유도할 수 있는 것들을 모두 수락하며
3. 거부된 첫 번째 토큰을 수정하거나 모두 수락된 경우 추가 토큰을 생성하기 위해 조정된 분포에서 토큰을 하나 더 샘플링하는 것이다.

이러한 방식으로 타겟 모델 $M_p$의 각 병렬 실행은 최소한 하나의 새로운 토큰을 생성하게 되므로(따라서 타겟 모델의 직렬 실행 횟수는 최악의 경우에도 단순 자기회귀 방법보다 많을 수 없다), $M_q$가 $M_p$를 얼마나 잘 근사하느냐에 따라 최대 $\gamma + 1$개의 새로운 토큰을 생성할 수 있다.
### Standardized Sampling
먼저 argmax, top-k, nuclues, 온도 설정 등 샘플링에는 많은 방법과 파라미터가 존재하며, 대중적인 구현체들은 보통 logit 수준에서 이를 다르게 처리하지만, 이 모든 것은 조정된 확률 분포로부터의 표준 샘플링으로 쉽게 변환될 수 있음을 유의하자.
예를 들어, argmax 샘플링은 분포에서 최대값이 아닌 요소들을 0으로 만들고 정규화하는 것과 동일하다.
따라서 우리는 확률 분포로부터의 표준 샘플링만 다루면 되며, 다른 모든 유형의 샘플링을 해당 프레임워크로 변환할 수 있다.

앞으로 $p(x)$와 $q(x)$는 각각 $M_p$와 $M_q$에서 나온 분포이며, 샘플링 방법에 맞게 조정된 것으로 가정한다.
### Speculative Sampling
$x \sim p(x)$를 샘플링하기 위해 대신 $x \sim q(x)$를 샘플링하고, $q(x) \le p(x)$ 이면 이를 유지한다.
만약 $q(x) > p(x)$ 경우, $1 - \frac{p(x)}{q(x)}$의 확률로 샘플을 거부하고, 대신 조정된 분포 $p'(x) = norm(max(0, p(x) - q(x)))$에서 $x$를 다시 샘플링한다.
임의의 분포 $p(x)$와 $q(x)$에 대해 이러한 방식으로 샘플링된 $x$가 실제로 $x \sim p(x)$임을 보이는 것은 간단하다(아래 참조).
![[Pasted image 20260716114636.png]]
조건부 접두사(prefix)에서 $M_q$를 실행하여 얻은 분포 $q(x)$가 주어지면, 토큰 $x_1 \sim q(x)$를 샘플링할 수 있다.
그런 다음 접두사에서 $M_p$를 실행하여 분포 $p(x)$를 계산하는 동시에, 접두사 + $[x_1]$에서 $M_p$를 실행하여 다음 토큰 $x_2$의 분포를 추측적으로 계산한다.
$x_1$이 거부되면 $x_2$의 계산을 폐기하고 조정된 분포에서 $x_1$을 다시 샘플링하며, $x_1$이 수락되면 두 토큰을 모두 유지한다.
알고리즘 1은 이 아이디어를 일반화하여 한 번에 1개에서 $\gamma + 1$개의 토큰을 샘플링한다.

## Analysis
### Number of Generated Tokens
타겟 모델에 대한 직렬 호출 횟수의 감소 계수, 즉 알고리즘 1의 단일 실행으로 생성되는 예상 토큰 수를 분석해보자.
접두사 $x_{<t}$가 주어졌을 때의 수학률 $\beta_{x<t}$는 추측적 샘플링을 통해 $x_t \sim q(x_t|x{<t})$를 수락할 확률이다.
$E(\beta)$는 $M_q$가 $M_p$를 얼마나 잘 근사하는지를 나타내는 자연스러운 척도이다.

$\beta$들이 i.i.d라고 가정하고 $\alpha = E(\beta)$라고 표기하면, 알고리즘 1의 단일 실행으로 생성되는 토큰 수는 성 확률 $1-\alpha$와 상한 $\gamma + 1$을 갖는 캡이 씌워진 기하 변수이며, 알고리즘 1에 의해 생성되는 예상 토큰 수는 아래 식을 만족한다.
$$
E(\# \text{ generated tokens}) = \frac{1 - \alpha^{\gamma + 1}}{1 - \alpha}
$$
### Calculating $\alpha$
이제 접두사와 두 모델 $M_p$ 및 $M_q$가 주어졌을 때 $\alpha$를 계산하기 위한 간단한 공식을 유도하자.
natural divergence $D_{LK}$를 정의하며 시작한다.
$$
D_{LK}(p,q) = \sum_x |p(x) - M(x)| = \sum_x |q(x) - M(x)|, \quad M(x) = \frac{p(x)+q(x)}{2}
$$
이때 $D_{LK}(p,q) = 1 - \sum_x \min(p(x), q(x))$가 된다. 증명은 아래와 같다.
![[Pasted image 20260716131813.png|400]]
이때 $D_{LK}(p,q)$는 $[0,1]$에서 대칭 발산(symmetric divergence)이다.
$$
\begin{align*}
D_{LK}(p,q) = 0 &\iff p = q. \\
D_{LK}(p,q) = 1 &\iff p \text{ and } q \text{ have disjoint support.}
\end{align*}
$$

### Walltime Improvement
i.i.d. 가정하에 본 알고리즘은 타겟 모델에 대한 호출 횟수를 $\frac{1 - \alpha^{\gamma + 1}}{1 - \alpha}$배만큼 줄여줌을 보였다.
월타임 분석을 위해, 월타임 증가 없이 $M_p$의 동시 평가를 $\gamma + 1$개만큼 병렬로 실행할 수 있다고 가정하자.
전체 월타임 개선을 얻기 위해, 이제 근사 모델 $M_q$를 실행하는 비용을 고려하자.
비용 계수 $c$를 $M_q$의 단일 실행 시간과 $M_p$의 단일 실행 시간의 비율로 정의하면, 알고리즘 1에 의한 전체 월타임의 기대 개선 계수는 $\frac{1-\alpha^{\gamma+1}}{(1-\alpha)(\gamma c+1)}$이 된다. 증명은 다음과 같다.
![[Pasted image 20260716132909.png|400]]
이때 만약 $\alpha > c$라면, 개선을 얻을 수 있는 $\gamma$가 존재하며, 개선 계수는 최소 $\frac{1 + \alpha}{1 + c}(\gamma = 1)$가 된다.
### Number of Arithmetic Operations
알고리즘 1은 $M_p$를 $\gamma + 1$번 병렬로 실행하므로, 동시 산술 연산 횟수는 $\gamma + 1$배만큼 증가한다.
이제 알고리즘 1은 실행당 최대 $\gamma + 1$개의 토큰을 생성하므로, 전체 산술 연산 횟수는 표준 디코딩 알고리즘보다 많을 수 있다.
$M_q$로부터의 샘플을 수락할 때 증가된 동시성은 무료이며 전체 연산 횟수는 증가하지 않는다.
그러나 추측을 거부할 때는 연산이 낭비된다. 이제 전체 산술 연산 횟수에 대한 본 방법의 영향을 분석해보자.

$\hat{c}$를 근사 모델 $M_q$의 토큰당 산술 연산 횟수와 타겟 모델 $M_p$의 토큰당 산술 연산 횟수의 비율로 정의한다.
이때 알고리즘 1의 전체 연산 횟수 증가에 대한 기대 계수는 $\frac{(1-\alpha)(\gamma\hat{c}+\gamma+1)}{1-\alpha^{\gamma+1}}$이 된다. 증명은 다음과 같다.
![[Pasted image 20260716134528.png|400]]
전체 산술 연산 횟수와 달리, 전체 메모리 접근 횟수는 본 방법으로 줄어들 수 있다.
구체적으로, 타겟 모델의 가중치와 KV 캐시는 알고리즘 1의 실행당 한 번 읽을 수 있으므로, 이를 읽기 위한 메모리 접근 횟수는 $\frac{1 - \alpha^{\gamma + 1}}{1 - \alpha}$배만큼 줄어든다.
### Chossing $\gamma$
$c$와 $\alpha$가 주어지고 충분한 컴퓨팅 자원이 있다고 가정할 때, 최적의 $\gamma$는 월타임 개선 방정식을 최대화하는 값이다.

$\beta$가 상수가 아니기 때문에 $\alpha$에 기반하여 단일 $\gamma$ 값 선택하는 대신, $\beta$ 값을 예측하고 그에 따라 알고리즘 1을 실행하는 동안 $\gamma$ 값을 변화시킴으로써 추가적인 개선을 얻을 수 있다.
