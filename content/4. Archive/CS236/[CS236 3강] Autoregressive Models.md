## 1. 생성 모델의 핵심 목표와 자기회귀의 정의
생성 모델은 미지의 데이터 분포 $P_{data}$로부터 추출된 샘플을 학습하여 모델 분포 $P_\theta$를 데이터 분포에 최대한 가깝게 최적화하는 것을 목표로 한다. 생성 모델의 주요 기능은 다음과 같다:
1. **생성 (Generation):** 모델에서 새로운 샘플 $x_{new} \sim P(x)$를 추출하는 과정.
2. **밀도 추정 (Density Estimation):** 입력 데이터 $x$가 데이터 분포에 속할 확률 $P(x)$를 평가하여 이상치 여부를 판단함.
3. **무감독 표현 학습 (Unsupervised Representation Learning):** 데이터의 공통적인 특징(feature)을 스스로 학습함.
**자기회귀 모델**은 데이터 $x = (x_1, \dots, x_n)$의 결합 확률을 다음과 같이 연쇄 법칙을 통해 모델링하는 방식이다: $$p(x_1, \dots, x_n) = \prod_{i=1}^{n} p(x_i | x_1, \dots, x_{i-1})$$이는 어떤 가정도 필요 없는 일반적인 수식이지만, 변수가 늘어날수록 조건부 확률 테이블(CPT)의 크기가 기하급수적으로 커지는 문제를 해결하기 위해 신경망(Neural Models)을 활용한다.
## 2. 자기회귀 모델의 주요 아키텍처 분석
### 2.1 Fully Visible Sigmoid Belief Network (FVSBN)
가장 초기 형태의 모델로, 각 조건부 확률을 로지스틱 회귀 모델로 정의한다.
- **구조:** 각 픽셀 $x_i$를 이전 모든 픽셀 $x_{<i}$의 선형 결합에 시그모이드 함수를 적용하여 예측한다.
- **파라미터 수:** $O(n^2)$ (픽셀 수의 제곱에 비례).
- **한계:** 모델의 유연성이 부족하여 복잡한 이미지 구조(예: Caltech 101)를 캡처하지 못하고 뭉쳐진 형태(blobs)의 결과물만 생성하는 경향이 있다.
### 2.2 Neural Autoregressive Density Estimation (NADE)
로지스틱 회귀 대신 1계층 신경망을 사용하여 유연성을 높인 모델이다.
- **가중치 공유 (Weight Tying):** 각 예측 단계에서 사용하는 가중치 행렬을 공유하여 파라미터 수를 $O(n)$으로 줄이고 계산 속도를 향상시켰다.
- **파라미터 수:** 은닉 유닛의 차원이 $d$일 때, 가중치 행렬 $W \in \mathbb{R}^{d \times n}$과 편향 등을 포함하여 n에 선형적으로 비례한다.
- **RNADE:** 연속형 데이터를 모델링하기 위해 조건부 확률의 출력을 가우시안 혼합 모델(Mixture of Gaussians)의 파라미터($\mu$, $\sigma$)로 설정한 확장 모델이다.
### 2.3 Masked Autoencoder for Distribution Estimation (MADE)
![[Pasted image 20260203130056.png|400]]
오토인코더 구조를 활용하되, 자기회귀 속성을 유지하기 위해 특정 연결을 마스킹(Masking)하는 기법을 도입했다.
- **핵심 아이디어:** 일반적인 오토인코더는 입력 전체를 참조하여 출력을 생성하므로 "부정행위(cheating)"가 발생할 수 있다. MADE는 마스크를 통해 $x_i$를 예측할 때 오직 $x_{<i}$만 사용하도록 제한한다.
- **장점:** NADE가 n번의 패스를 필요로 하는 것과 달리, 단 한 번의 순전파(single forward pass)로 모든 조건부 확률 파라미터를 계산할 수 있어 훈련이 매우 효율적이다.
## 3. 시퀀스 데이터 모델링: RNN 및 변형 모델
시퀀스 데이터의 경우 과거 이력(history)이 길어짐에 따라 고정된 파라미터로 이를 처리하는 아키텍처가 필요하다.
### 3.1 순환 신경망 (RNN)
과거 정보를 은닉 상태(Hidden State, $h_t$)에 요약하여 전달한다.
- **업데이트 규칙:** $h_{t+1} = \tanh(W_{hh}h_t + W_{xh}x_{t+1})$
- **특징:** 입력 길이 $n$에 관계없이 파라미터 수가 일정하며(constant), 이론적으로 모든 계산 가능한 함수를 표현할 수 있다.
- **한계:** 학습 시 시퀀스를 펼쳐야 하므로 병렬화가 불가능하고(매우 느림), 긴 시퀀스에서 그래디언트 소실/폭주 문제가 발생할 수 있다.
### 3.2 PixelRNN 및 PixelCNN
이미지 데이터를 자기회귀적으로 모델링하기 위한 전용 모델이다.
- **PixelRNN:** LSTM 기반으로 래스터 스캔 순서에 따라 픽셀을 생성한다. 성능은 우수하나 매우 느리다.
- **PixelCNN:** 마스크된 컨볼루션(Masked Convolutions)을 사용하여 주변 픽셀 맥락을 파악한다. 컨볼루션의 특성상 병렬 처리가 가능하여 PixelRNN보다 훨씬 빠르며 유사한 성능을 낸다.
## 4. 모델 비교 및 성능 평가

| 모델 유형        | 파라미터 복잡도           | 훈련 효율성 | 주요 특징                   |
| ------------ | ------------------ | ------ | ----------------------- |
| **FVSBN**    | $O(n^2)$           | 낮음     | 단순 로지스틱 회귀 기반           |
| **NADE**     | $O(n)$             | 보통     | 가중치 공유를 통한 파라미터 절감      |
| **MADE**     | $O(n)$             | 높음     | 오토인코더 마스킹을 통한 단일 패스 계산  |
| **RNN**      | $O(1)$ (w.r.t $n$) | 매우 낮음  | 임의 길이 시퀀스 처리, 순차적 연산 필수 |
| **PixelCNN** | 고정됨                | 높음     | 컨볼루션 병렬화, 마스크된 필터 사용    |
## 5. 응용 분야 및 한계
### 5.1 주요 응용
- **텍스트 생성:** 캐릭터 단위 RNN은 셰익스피어 문체, 위키피디아 마크다운 문법, 아기 이름 등을 놀라운 수준으로 학습할 수 있다.
- **음성 합성:** **WaveNet**은 확장된 컨볼루션(Dilated Convolutions)을 사용하여 넓은 수용 영역(receptive field)을 확보, 고품질 음성을 생성한다.
- **이상치 탐지 및 방어:** **PixelDefend**는 정상 이미지 분포 $P(x)$를 학습한 후, 낮은 확률을 가진 적대적 예제(Adversarial Examples)를 탐지하고 정화하는 데 사용된다.
### 5.2 기술적 한계
1. **순차적 생성:** 데이터를 생성할 때 이전 결과가 반드시 필요하므로 샘플링 과정이 근본적으로 순차적이며 느리다.
2. **맥락 요약의 어려움:** RNN의 경우 모든 과거 이력을 단일 벡터($h_t$)에 압축해야 하는 병목 현상이 발생한다. 이를 해결하기 위해 최근에는 **어텐션(Attention)** 메커니즘을 사용하는 트랜스포머 아키텍처가 주류를 이루고 있다.
3. **특징 추출:** 자기회귀 모델은 확률 추정에는 강력하지만, 데이터의 구조를 파악하거나 군집화하는 등 유용한 특징을 직접 추출하는 데에는 다른 모델(예: VAE)보다 덜 자연스럽다.
