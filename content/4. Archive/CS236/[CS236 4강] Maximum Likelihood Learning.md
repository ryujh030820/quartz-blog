## 1. 핵심 요약 (Executive Summary)
본 문서는 스탠퍼드 대학교 CS236 강의 내용을 바탕으로, 생성 모델(Generative Models)의 핵심인 **자기회귀 모델(Auto-regressive Models)** 의 구조적 진화와 **최대 우도 학습(Maximum Likelihood Learning)** 의 수학적 원리를 분석한다.
주요 통찰은 다음과 같다:
- **아키텍처의 전환:** 순환 신경망(RNN)의 병목 현상과 순차적 계산 한계를 극복하기 위해, 전체 문맥을 병렬로 처리할 수 있는 **어텐션(Attention) 및 트랜스포머(Transformer)** 구조가 현대 생성 모델의 표준으로 자리 잡았다.
- **학습의 본질:** 생성 모델 학습은 데이터 분포($P_{data}$)와 모델 분포($P_\theta$) 사이의 **KL 발산(KL-Divergence)** 을 최소화하는 과정이며, 이는 수학적으로 **로그 우도(Log-likelihood)** 를 최대화하는 것과 동일하다.
- **정보 이론적 연관성:** KL 발산은 잘못된 분포를 기반으로 데이터를 압축할 때 발생하는 '추가 비트(extra bits)'를 의미하며, 따라서 모델 학습은 데이터의 최적 압축 방식을 찾는 과정으로 해석될 수 있다.
- **일반화의 과제:** 고차원 데이터의 희소성(Sparse coverage)으로 인해 발생하는 **편향-분산 트레이드오프(Bias-Variance Trade-off)** 를 해결하는 것이 모델의 일반화 성능을 결정짓는 핵심 요소이다.
## 2. 자기회귀 모델의 구조적 진화
자기회귀 모델은 이전 토큰이나 픽셀을 기반으로 다음 요소를 예측하는 방식으로 데이터를 모델링한다.
### 2.1 RNN에서 트랜스포머로의 전환
- **RNN의 한계:**
    - **병목 현상:** 단일 은닉 벡터($H_t$)가 이전의 모든 정보를 요약해야 하므로 정보 손실이 발생한다.
    - **학습 속도:** 계산을 순차적으로 수행(unroll)해야 하므로 병렬 처리가 어렵고 속도가 느리다.
    - **기울기 문제:** 장기 의존성(Long dependencies)으로 인해 기울기 소실(Vanishing) 또는 폭주(Exploding) 문제가 발생하기 쉽다.
- **어텐션 및 트랜스포머의 이점:**
    - **선택적 집중:** 어텐션 메커니즘을 통해 현재 예측에 중요한 이전 단계의 특정 요소에 직접 접근할 수 있다.
    - **병렬성:** 학습 시 모든 위치의 계산을 동시에 수행할 수 있어 대규모 데이터셋 확장이 용이하다.
    - **인과적 마스킹(Causal Masking):** 미래의 정보를 참조하지 못하도록 마스크를 사용하여 자기회귀 속성을 유지한다.
### 2.2 이미지 모델링 (PixelCNN 및 PixelRNN)
- 이미지를 픽셀의 시퀀스(주로 좌상단에서 우하단 순서)로 처리한다.
- **PixelCNN:** 마스크된 컨볼루션 커널을 사용하여 자기회귀 구조를 유지하면서도 병렬 계산을 가능하게 한다. 다만, 특정 아키텍처 구조로 인해 '사각지대(blind spot)'가 발생할 수 있어 이를 해결하기 위한 추가적인 트릭이 필요하다.
- **응용:** 이상 탐지(Anomaly Detection)에 유용하다. 학습된 모델은 자연스러운 이미지에 높은 우도를, 조작된 이미지(적대적 공격 등)에 낮은 우도를 할당하여 이를 구분해낸다.
## 3. 최대 우도 학습(MLE)의 원리와 수학적 기초
생성 모델의 목표는 미지의 데이터 분포 $P_{data}$를 가장 잘 근사하는 파라미터 $\theta$를 찾는 것이다.
### 3.1 [[[개념 정리] KL Divergence|KL 발산(KL-Divergence)]]
두 확률 분포 $p$와 $q$ 사이의 유사성을 측정하는 척도이다.
$$D(p \parallel q) = \sum_x p(x) \log \frac{p(x)}{q(x)}$$
- **특성:** 항상 0 이상이며, $p=q$일 때만 0이 된다. 비대칭적($D(p \parallel q) \neq D(q \parallel p)$)이다.
- **압축 손실:** 정보 이론적으로, 데이터가 p에서 생성되었을 때 q를 기반으로 한 압축 코드를 사용할 경우 발생하는 평균적인 추가 비트 수를 의미한다.
### 3.2 MLE로의 단순화
KL 발산을 최소화하는 것은 다음 식을 최대화하는 것과 수학적으로 동일하다.
$$\arg \min_{P_\theta} D(P_{data} \parallel P_\theta) = \arg \max_{P_\theta} E_{x \sim P_{data}} [\log P_\theta(x)]$$
즉, 실제 데이터 샘플에 대해 모델이 부여하는 로그 확률의 기댓값을 최대화하는 것이 모델 학습의 핵심이다.
## 4. 최적화 및 몬테카를로 추정 (Monte Carlo Estimation)
실제 학습에서는 전체 데이터 분포 $P_{data}$를 알 수 없으므로 표본을 통한 근사가 필요하다.
### 4.1 몬테카를로 근사

기댓값을 계산하기 위해 전체 공간을 탐색하는 대신, 데이터셋 D에서 추출한 샘플들의 평균으로 이를 대체한다.
$$E_{x \sim P_{data}} [\log P_\theta(x)] \approx \frac{1}{|D|} \sum_{x \in D} \log P_\theta(x)$$
샘플 수($T$)가 증가할수록 추정치의 분산은 $V[g(x)]/T$ 비율로 감소하여 참값에 수렴한다.
### 4.2 확률적 경사 하강법 (SGD)
데이터셋이 매우 클 경우, 매 단계 전체 데이터의 기울기를 계산하는 것은 불가능하다. 따라서 미니배치(Mini-batch)를 사용하여 기울기의 몬테카를로 추정치를 구하고 파라미터를 업데이트한다.
$$\nabla_\theta \ell(\theta) \approx \frac{m}{|B|} \sum_{x \in B} \nabla_\theta \log P_\theta(x)$$
## 5. 학습의 한계와 일반화 (Generalization)
성공적인 학습은 단순히 훈련 데이터를 암기하는 것이 아니라, 보지 못한 데이터(Unseen samples)에 대해서도 높은 확률을 부여하는 능력을 의미한다.
### 5.1 차원의 저주와 희소성
- 예를 들어, $28 \times 28$ 이진 이미지(MNIST)의 가능한 상태 수는 $2^{784} \approx 10^{236}$개에 달한다.
- 수억 개의 훈련 샘플이 있더라도 전체 가능성에 비하면 극히 일부(Sparse coverage)에 불과하며, 이는 학습을 근본적으로 어렵게 만든다.
### 5.2 편향-분산 트레이드오프 (Bias-Variance Trade-off)

|                      |                           |                                |
| -------------------- | ------------------------- | ------------------------------ |
| 구분                   | 특징                        | 문제점                            |
| **높은 편향 (Bias)**     | 모델 공간이 너무 제한적임 (예: 선형 모델) | 데이터의 실제 구조를 학습하지 못함 (**과소적합**) |
| **높은 분산 (Variance)** | 모델이 너무 유연함 (예: 고차 다항식)    | 훈련 데이터의 노이즈까지 암기함 (**과적합**)    |

### 5.3 과적합 방지 전략
- **모델 구조 제한:** 더 작은 신경망 사용, 가중치 공유(Weight sharing).
- **정규화(Regularization):** 목적 함수에 모델 복잡도에 대한 페널티(R(M)) 추가.
- **검증:** 보관해둔 검증 데이터셋(Validation set)을 통해 일반화 성능을 지속적으로 평가.
- **오컴의 면도날(Occam's Razor):** 성능이 동일하다면 더 간단한 모델을 선호하는 원칙 적용.
