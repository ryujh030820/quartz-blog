## 1. 잠재 변수 모델로서의 VAE 개요
VAE는 간단한 구성 요소를 결합하여 복잡한 한계 분포 $p(x)$를 정의하는 생성 모델이다.
### 1.1 생성 과정
1. **잠재 변수 샘플링:** 가장 단순한 분포인 다변량 가우시안(평균 0, 공분산 단위 행렬 $I$)에서 잠재 변수 $z$를 추출한다.
2. **신경망 통과:** 추출된 $z$를 두 개의 신경망 $\mu_\theta(z)$와 $\Sigma_\theta(z)$에 통과시켜 또 다른 가우시안 분포의 매개변수를 얻는다.
3. **데이터 생성:** 조건부 분포 $p(x|z)$에서 샘플링하여 실제 데이터 포인트 $x$를 생성한다.
### 1.2 모델의 유연성과 한계
- **유연성:** 개별 조건부 분포는 가우시안으로 단순하지만, 무한한 수의 가우시안 분포를 혼합한 것과 같기 때문에 매우 복잡한 $p(x)$를 표현할 수 있다.
- **학습의 어려움(No Free Lunch):** 자기 회귀 모델과 달리 주변 우도 $p(x)$를 계산하기 위해 모든 가능한 $z$에 대해 적분해야 하므로 우도 평가와 최적화가 매우 비용이 많이 들고 어렵다.
## 2. 변분 추론과 증거 하한(ELBO)
학습의 어려움을 해결하기 위해 보조 추론 모델(Auxiliary Inference Model) $q$를 도입하여 잠재 변수를 추론한다.
### 2.1 ELBO의 유도
젠센의 부등식(Jensen's Inequality) 또는 KL 발산(Kullback-Leibler Divergence)의 비음수성을 활용하여 다음의 하한선을 도출할 수 있다.
$$\log p(x; \theta) \ge \mathbb{E}_{q(z)} [\log p_\theta(x, z)] + H(q)$$
- **재구성 항:** 모든 변수가 관찰된 것처럼 로그 우도를 계산하는 부분이다.
- **엔트로피 항:** 분포 $q$의 무작위성(Uncertainty)을 나타내는 항이다.
### 2.2 최적의 $q$ 선택
- $q(z)$가 사후 분포 $p(z|x; \theta)$와 일치할 때, 불평등은 등식이 되며 ELBO는 주변 우도와 정확히 일치한다.
- 실제로는 사후 분포를 계산하는 것이 불가능(Intractable)하므로, 다룰 수 있는(Tractable) 분포 가족 중에서 최적의 매개변수 $\phi$를 찾는 최적화 문제로 전환한다.
## 3. 핵심 최적화 기법
### 3.1 재매개변수화 트릭 (Reparameterization Trick)
$\phi$에 대한 그래디언트를 계산할 때, 기대값의 대상이 되는 분포가 $\phi$에 의존하면 몬테카를로 샘플링을 통한 직접적인 미분이 어렵다.
- **해결책:** 확률적 샘플링 과정을 결정론적인 변환 과정으로 재정의한다.
    - 예: $z \sim \mathcal{N}(\mu, \sigma^2)$를 $z = \mu + \sigma \epsilon$ (단, $\epsilon \sim \mathcal{N}(0, I)$)으로 변환.
- **장점:** 그래디언트가 확률적 노드 $\epsilon$을 우회하여 매개변수 $\mu$, $\sigma$로 직접 흐를 수 있게 되어 분산이 낮은 효율적인 학습이 가능해진다.
### 3.2 분할 상환 추론 (Amortized Inference)
데이터셋이 클 경우 각 데이터 포인트 $x_i$마다 개별적인 변분 매개변수 $\phi_i$를 최적화하는 것은 불가능하다.
- **방식:** 데이터 $x$를 입력받아 최적의 $\phi$를 예측하는 단일 신경망(인코더) $f_\lambda(x)$를 학습시킨다.
- **효과:** 새로운 데이터에 대해 최적화 문제를 풀 필요 없이 단 한 번의 순전파(Feed-forward pass)만으로 사후 분포를 추정할 수 있다. 이를 '추론 비용을 분할 상환한다'고 표현한다.
## 4. VAE의 오토인코더 관점 해석
VAE의 ELBO 목적 함수는 두 가지 항의 합으로 해석될 수 있으며, 이는 전통적인 오토인코더 구조와 유사하다.

|         |                      |                           |
| ------- | -------------------- | ------------------------- |
| 구성 요소   | 역할                   | 오토인코더 해석                  |
| **인코더** | $q_\phi(z \mid x)$   | 입력 $x$로부터 잠재 분포의 매개변수를 추출 |
| **디코더** | $p_\theta(x \mid z)$ | 잠재 변수 $z$로부터 데이터 $x$를 복원  |
|         |                      |                           |
![[Pasted image 20260321222248.png]]
### 목적 함수의 두 기능
1. **재구성 손실 최적화:** $x$가 $p(x|z)$ 하에서 높은 확률을 갖도록 하여 입력 데이터와 복원 데이터가 유사하도록 강제한다.
2. **정규화 (KL Divergence):** 잠재 분포 $q_\phi(z|x)$가 사전 분포 $p(z)$(예: 표준 정규 분포)와 유사하도록 강제하여 잠재 공간에 구조를 부여한다.
## 5. 주요 통찰 및 연구 방향
"VAE는 오토인코더를 생성 모델로 전환하는 방법으로 생각할 수 있습니다."
- **성능의 트레이드오프:** 더 강력한 디코더(예: PixelCNN)를 사용하면 잠재 코드를 무시하는 현상이 발생할 수 있다. 우도가 높다고 해서 반드시 샘플의 질이 좋은 것은 아니다.
- **계층적 구조:** VAE를 여러 층으로 쌓으면 더 강력한 모델이 되며, 이를 극단적으로 확장한 것이 확산 모델(Diffusion Models)의 기초가 된다.
- **비감독 학습의 도구:** VAE는 K-평균(K-means)의 확장판으로 볼 수 있으며, 데이터에 숨겨진 복잡한 변동 요인(Latent Factors of Variation)을 발견하는 데 유용하다.
## 중요 인용구 (Key Quotes)
- "무료 점심은 없습니다(No free lunch). 우도를 평가하기 어렵다는 것이 이 모델이 지불해야 하는 대가입니다."
- "ELBO가 타이트해질수록(즉, $q$가 사후 분포에 가까워질수록) 우리가 최적화하고자 하는 실제 우도값에 더 가까워집니다."
- "재매개변수화 트릭은 샘플링 과정을 결정론적 변환으로 재작성하여 자동 미분(Auto-diff)을 가능하게 합니다."
- "분할 상환 추론은 신경망이 당신을 위해 최적화 문제를 대신 풀어주는 학습 과정입니다."
